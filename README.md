# 오늘도 덥습니다 ☀️

폭염주의보·폭염경보 발령을 자동으로 감지해 **Mattermost 채널에 더위 안전 카드**를 올리는 캠페인 봇입니다.

```
[GitHub Actions · 매일 아침 9시(KST)]
        │
        ├─▶ 기상청 특보 통보문    ──▶ t6(현재 발효 현황) 파싱 → 우리 구역의 폭염 특보
        └─▶ 기상청 단기예보 API   ──▶ 오늘 최고/최저기온
                    │
                    ▼
        특보 있음 ─▶ 특보 카드 (행동요령)
        특보 없음 ─▶ 예보 카드 (기온 등급 + 한 줄 멘트)
                    │
                    ▼
        [하루 1회 중복 필터] ──▶ Mattermost Incoming Webhook
```

**매일 아침 카드가 한 장은 반드시 올라갑니다.** 특보가 없는 날에는 오늘 최고기온으로
등급을 매겨 가벼운 멘트를 붙입니다. 조용한 날이 없는 대신, 매일 아침 뉴스처럼 읽힙니다.

| 낮 최고 | 등급 | 멘트 |
|---|---|---|
| 35℃ 이상 | 🫠 가마솥 | 오늘도 덥습니다. 아니, 오늘은 좀 심하게 덥습니다. |
| 33℃ 이상 | 🥵 한여름 | 네, 오늘도 덥습니다. 예상하셨겠지만요. |
| 30℃ 이상 | 😮‍💨 더움 | 오늘도 덥습니다. 놀랍지 않으시죠. |
| 28℃ 이상 | 😌 살짝 더움 | 오늘은 좀 덜 덥습니다. 그래도 덥긴 합니다. |
| 그 미만 | 🍃 선선 | 오늘은… 안 덥습니다. 이런 날도 있습니다. |

멘트는 등급마다 3~4개씩 두고 **날짜로 돌려가며** 고릅니다. 같은 등급이 며칠 이어져도
매일 다른 문장이 나오고, 같은 날 여러 번 실행하면 항상 같은 문장이 나옵니다.

특보가 **오늘 새로 발효된 경우**에는 카드 제목에 `오늘 발효` 배지가 붙어,
며칠째 이어지는 특보와 구분됩니다.

특보 등급은 세 단계입니다: 🚨 `폭염중대경보` > 🔥 `폭염경보` > 🌡️ `폭염주의보`.

## 준비물

### 1. 기상청 API 키

[공공데이터포털](https://www.data.go.kr/data/15000415/openapi.do)에서 아래 두 개를 활용신청합니다.

- 기상청_기상특보 조회서비스 (감지)
- 기상청_단기예보 조회서비스 (카드에 표시할 기온)

마이페이지에서 **일반 인증키(Decoding)** 를 복사합니다.
Encoding 키를 쓰면 이중 인코딩되어 실패하니 주의하세요.

### 2. Mattermost Incoming Webhook

통합 기능(Integrations) → Incoming Webhook → 채널 선택 → URL 복사.

## 로컬 실행

```bash
pip install -r requirements.txt
cp .env.example .env   # 값 채우기
```

```bash
python main.py --demo
```

API 호출 없이 카드 모양만 미리 봅니다. 실제 조회는 아래처럼 합니다.

```bash
python main.py --dry-run
```

전송 없이 감지 결과와 페이로드만 출력합니다. 이상 없으면 그냥 `python main.py`.

| 옵션 | 설명 |
|---|---|
| `--demo` | API 없이 샘플 카드 출력 |
| `--dry-run` | 실제 조회하되 전송은 안 함 |
| `--force` | 중복 방지 무시하고 다시 보냄 (디자인 확인용) |

응답 원본을 확인하고 싶으면:

```bash
python probe.py warn   # 특보 목록
python probe.py msg    # 통보문 t6 (지역 상세)
```

## GitHub Actions 설정

레포 **Settings → Secrets and variables → Actions** 에 두 개를 등록합니다.

| 이름 | 값 |
|---|---|
| `KMA_SERVICE_KEY` | 공공데이터포털 일반 인증키(Decoding) |
| `MM_WEBHOOK_URL` | Mattermost Webhook URL |

등록 후 Actions 탭에서 `오늘도 덥습니다` → **Run workflow** → 모드를 고르고 실행합니다.

| 모드 | 하는 일 |
|---|---|
| `dry-run` | 감지만 하고 전송하지 않음 (기본값) |
| `send` | 실제 발송 |
| `probe` | 특보 목록 원본을 로그에 출력 |
| `probe-msg` | 통보문 t6(구역별 현황)를 로그에 출력 |

스케줄 실행은 항상 `send`입니다.

## 지역 변경

[src/config.py](src/config.py)의 `REGIONS`만 고치면 됩니다.

```python
Region(
    name="서울 강남구",       # 카드에 표시할 이름
    stn_id="108",             # 통보문 발표관서. 108=본청(전국 현황)
    nx=61, ny=125,            # 단기예보 격자 (역삼동)
    warn_area="서울",         # t6의 최상위 지역 표기
    sub_area="서울동남권",    # t6 괄호 안의 구역. 하위 구역이 없으면 None
)
```

여러 지역을 넣으면 각각 따로 감지해 카드를 만듭니다.

서울의 특보 구역은 네 개입니다.

| 구역 | 해당 구 |
|---|---|
| 서울동남권 | 강남·서초·송파·강동 |
| 서울동북권 | 성북·강북·도봉·노원·중랑·동대문·광진·성동 |
| 서울서남권 | 강서·양천·구로·금천·영등포·동작·관악 |
| 서울서북권 | 은평·서대문·마포·종로·중구·용산 |

## 특보를 어떻게 읽는가

특보 **목록**의 제목에는 지역 정보가 전혀 없습니다.

```
[특보] 제07-448호 : 2026.07.29.10:00 / 폭염중대경보·폭염경보 변경 (*)
```

대신 **통보문의 `t6` 필드**에 현재 발효 현황이 구역 단위로 들어 있습니다.

```
o 폭염중대경보 : 경상남도(양산, 김해, 밀양, 의령, 창녕)
o 폭염경보    : 경기도(고양, 남양주, …), 서울(서울서북권 제외), 인천(인천북부), 대전
o 폭염주의보  : 경기도(광명, 과천, …), 서울(서울서북권)
o 열대야주의보 : …, 서울, …
```

지역 표기는 세 형태이고, [src/status.py](src/status.py)가 이를 해석합니다.

| 표기 | 의미 |
|---|---|
| `서울` | 서울 전역 |
| `서울(서울서북권)` | 그 구역만 |
| `서울(서울서북권 제외)` | 그 구역만 빼고 전역 |

`완도(여서도 제외)`처럼 괄호가 중첩되므로, 쉼표 분리는 괄호 깊이를 세면서 합니다.

**`stnId=108`은 서울이 아니라 본청입니다.** t6에 전국 현황이 담기므로 이 값이 맞습니다.
지역 판정은 `warn_area`/`sub_area`가 담당합니다.

신규 발효와 해제는 **최신 통보문과 어제 이전 통보문의 t6를 비교**해 알아냅니다.
어제 통보문을 못 구하면 신규 여부를 알 수 없으므로 아무것도 신규로 단정하지 않습니다.

응답 형식이 바뀌면 `probe`(목록) / `probe-msg`(통보문) 모드로 원본을 확인하세요.

## 중복 발송 방지

특보는 며칠씩 이어지므로 매일 아침 같은 특보가 다시 잡힙니다.
중복 방지 키에 **날짜를 포함**시켜, 발효가 이어져도 **하루에 한 번만** 카드가 올라갑니다.
키는 `state/sent.json`에 남고 Actions가 이 파일을 레포에 다시 커밋해 실행 사이에 상태를 유지합니다.
7일이 지난 키는 자동으로 정리됩니다.

## 알려진 제약

- **GitHub Actions cron은 정시에 실행되지 않습니다.** 부하에 따라 수 분~수십 분 밀립니다.
  9시 정각이 중요하면 상시 구동 서버의 cron으로 옮기세요.
- 특보 목록 조회는 **오늘 기준 6일 전까지만** 가능합니다(초과 시 `resultCode 99`).
  발효 판정은 t6(현재 현황)를 쓰므로 이 제한과 무관하지만, 6일 안에 통보문이
  한 건도 없으면 현황을 못 가져옵니다(폭염철에는 사실상 매일 발표됩니다).
- `WARNING_LOOKBACK_DAYS`는 통보문을 찾기 위한 조회 범위입니다. 너무 줄이면
  비교용 어제 통보문을 못 찾아 신규/해제 판정이 빠집니다.
  기본값 `6`을 권장합니다.
- 특보 통보문은 발표 시각 단위라, 아침 9시 실행 시점의 최신 통보문이 어제 것일 수 있습니다.
  그 경우에도 t6는 현재 발효 현황이므로 판정은 정확합니다.
- 오늘의 `TMX`/`TMN`이 이미 지나 예보에서 빠지면 시간별 기온(`TMP`)의 최대·최소로 대신합니다.
  실제 일최고/최저와 다소 차이가 날 수 있습니다.

## 열대야에 대해

열대야는 **정식 기상특보로 존재합니다.** t6에도 `o 열대야주의보 : …, 서울, …` 로 나옵니다.
이 캠페인은 폭염에 집중하기로 해서 [src/status.py](src/status.py)의 `heat_warnings_for()`가
`폭염`으로 시작하는 이름만 남기도록 해두었습니다.

포함하려면 그 필터를 `("폭염", "열대야")`로 넓히고,
[src/card.py](src/card.py)의 `COLORS` / `ICONS` / `WARNING_HEADLINES` / `ACTION_GUIDE`에
항목을 추가하면 됩니다.
